# Project

This is a pharmaceutical competitive intelligence and evaluation tool.

The system collects and displays:
- Clinical trials
- PubMed publications
- News
- Patents
- Information about companies and technology platforms

Data is stored in a database and presented in a dashboard.

# General principles

- Only implement what was explicitly asked.
- Prefer the smallest possible code change.
- Do not refactor or restructure unless requested.
- Do not remove working logic without clear reason.
- If something seems wrong, explain before changing it.

# Before editing code

1. Read the relevant files.
2. Identify where the logic actually lives.
3. Check existing config/settings first.
4. Change as little code as possible.
